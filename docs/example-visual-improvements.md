## 0. 本轮采用的四条设计规则（来自调研）

| 规则 | 出处 | 落地方式 |
|---|---|---|
| 形变与数变**同帧** | 课标"几何直观 = 建立形与数的联系"；洋葱学园"图形—算式同步" | 图形旁常驻结果；推导链 chip 与图同步刷新；过程态出现"✓ 验证语" |
| 一个滑块控制**决定概念的量** | Mathigon 圆面积只用"等分份数"一个滑块；GeoGebra 滑动条=动态变量赋值器 | 新增「斜边水平偏移」「平均分的份数(4→64)」等参数 |
| **分步揭示**，不抢先给结论 | PhET implicit scaffolding / minimal text；Mathigon "Continue" | 初始态只给模型与操作项；"剪一剪/拼一拼/数一数/对折验证/滚一周"后才出现完成态 |
| 数学正确性**可被测试** | 本仓库既有约定（`validate.ts` + vitest） | 剪拼/旋转/反射/滚圆/等分几何全部抽成纯函数模块，用鞋带公式与坐标断言回归 |

新增纯几何模块（都被单元测试覆盖）：
- `g5/game/src/lib/labs/area.ts`（剪拼）、`g5/game/src/lib/labs/motion.ts`（平移/旋转/轴对称）
- `g6/game/src/lib/labs/circle.ts`（等分交错拼合、滚圆摆线）
