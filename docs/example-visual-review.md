# 六册上册例题可视化 Review 报告

> 生成日期：2026-08-09  \

> 证据：结构化数据、`docs/example-audit-glm.md`、本次 Playwright 截图 `docs/visual-review-screenshots/`。

## 1. 结论摘要

- 覆盖完整性：已覆盖 235 条例题；主截图 235/235 张，截图状态记录见 [manifest](visual-review-screenshots/manifest.json)。
- 题源准确性：沿用 GLM-OCR 核对结果，本次解析为 STRONG 200 / MEDIUM 27 / FIG 8 / 其他 0。
- 可视化优先级：P0 11 条，P1 85 条，P2 139 条，P3 0 条。
- 最主要的问题不是“有没有图”，而是很多题仍是通用组件套题：能算出答案，但缺少课本情境、数量关系、位值/单位/方向/步骤的视觉证据链。
- 明确发现 2 个真实渲染错误：`g3-c10-segment-more` 与 `g3-c10-times-word` 的 SVG `y` 属性写成字符串表达式，浏览器报错，线段图需先修复。
- 一年级 FIG 题和图内数量题应先做“课本原图校准”，再做美术升级；否则会把题源准确性风险包装成更漂亮但仍可能不准的互动。

## 2. 审查口径

| 维度 | 判断标准 | 本报告如何落地 |
|---|---|---|
| 题源准确 | 数字、页码、题干是否能被课本 OCR/图像印证 | 引用 `STRONG/MEDIUM/FIG`，但不把它等同于可视化准确 |
| 数学可视化准确 | 模型是否忠实表达数量、单位、空间关系、运算步骤 | 对每题给“准确性风险”和改进方案 |
| 呈现质量 | 学生是否能从图看出为什么这样算 | 关注视觉层级、关键量标注、过程动画、交互参数 |
| 截图证据 | 页面是否能稳定渲染，主可视化是否可见 | 每题链接一张截图，异常页面进入复核清单 |

### 优先级定义

- **P0 数学/渲染准确性**：已发现错误，或关键数量来自图内，或对象单位可能误导。
- **P1 概念模型准确性**：空间、单位、步骤、位值、线段图、几何关系等是核心，当前需要优先加强。
- **P2 呈现与交互质量**：题源基本准确，主要改进清晰度、情境贴合和反馈体验。
- **P3 细节打磨**：不影响理解的视觉/文案/动效微调；本轮没有单独把题列为 P3。

## 3. 共性问题与批量改进方向

| 问题 | 影响 | 批量改进 |
|---|---|---|
| 通用组件套题 | 同一个 kind 下不同例题看起来像同一模板，课本情境被削弱 | 在 `LabDef` 增加可选 `visualVariant/contextAssets/markers`，让同 kind 能按例题切换情境图层 |
| 结果重于过程 | 学生能看到答案，但看不到“为什么” | 所有计算类组件统一加“图 → 式 → 步骤 → 结论”的状态机，而不是静态图 + 文字步骤 |
| 单位与比例弱 | 长度、面积、质量、比例尺、圆等题若比例不准，会形成错误直觉 | 几何/度量组件优先使用统一比例尺、单位方格、刻度尺和尺寸标注 |
| 空间关系缺参照 | 方向、平移、旋转、轴对称、三视图容易缺少基准 | 固定显示方向箭头、旋转中心、对称轴、观察方向、对应点 |
| 低年级 emoji 过强 | emoji 能提高亲和力，但会牺牲一一对应、单位和原图真实性 | 一年级 FIG/计数题优先换成十框、可圈点阵、课本近似物件，而不是随机 emoji |
| 截图缺持续回归 | 目前截图是人工报告资产，未进入 CI | 后续可把截图脚本固化为 `scripts/visual-review`，对 P0/P1 题做视觉回归 |
