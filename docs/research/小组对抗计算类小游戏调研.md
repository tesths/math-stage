> **版本** v1.0 · 2026-11
> **面向** 4–6 年级 · 机制覆盖：同屏抢答 / 实时竞速 / 回合策略 / 卡牌棋类
> **服务对象** 现有 `math` 数学游戏站（`g1`–`g6`）的「对战专区」拓展；同时可用于课堂与数学节
> **方法说明** 本会话联网检索不可用（无 web 后端 API Key）。本方案依据成熟公开玩法（24 Game、Krypto、KenKen、Kakuro、Nim、Pig、Hex、Bulls & Cows、汉诺塔、Prime Climb 等）与既有教学经验整理，**未引用未核实的统计数据**；文末「灵感来源」列出可自行检索的经典出处，便于二次核对。

## 0. 一页速览

现有 `g1`–`g6` 游戏基本是**单人答题/口算**（如 `质数快抢`、`面积速算`、`化简比高手`）。本方案补上一块长期空白——**小组对抗类**，并刻意做"不简单"：不止练计算速度，更把**策略、博弈、估算、建模**嵌进对抗里。

## 1. 调研背景与目标

### 1.1 为什么补"小组对抗 + 计算"

- **单人 quiz 的天花板**：现有 `g1`–`g6` 的数十款单人游戏（每年级 10–20 款）解决了"即时反馈、可无限重玩"，但缺少**社会性**——学生之间没有博弈、没有谈判、没有"为团队负责"的临场压力，练习动机主要靠自律。
- **计算流畅度的最佳载体是"有对手"**：当"算错就丢分/丢地盘"时，学生自然追求**又对又快**，且会主动检查、主动用运算律走捷径——这正是课标强调的"运算能力"与"数感"。
- **高年级适合"计算之上再加一层"**：4–6 年级已具备分数、小数、百分数、比例、统计概率与简单逻辑，足够支撑**策略、博弈、估算、建模**类的深度对抗。这类游戏对学优生"够味"，对学困生也能靠"计算基础档"参与。

### 1.2 "高大上、不简单"的界定（三级素养阶梯）

我们不把"难"理解为"算得更大更繁"，而是让同一款游戏能同时触达三层：

| 阶梯 | 能力 | 游戏中的体现 | 例子 |
|---|---|---|---|
| **L1 计算流畅** | 又对又快地算 | 抢答、限时，答对才行动 | 算式接龙、质数快抢 |
| **L2 策略博弈** | 在对抗中做最优决策 | 资源分配、堵截、何时收手 | 大富翁、Hex、Pig |
| **L3 建模估算 / 论证** | 用数学描述现实、给理由 | 数量级估算、说明最优策略 | Fermi 擂台、尼姆博弈最优解 |

> 设计上每款游戏都写明"L1/L2/L3 入口"，老师可按班级水平只开某一层。

### 1.3 调研范围

- **桌面/卡牌经典**：24 Game、Krypto、KenKen、Kakuro、Nim、Pig、Hex、Bulls & Cows、Tower of Hanoi、Prime Climb。
- **游戏化平台模式**：Kahoot!、Blooket、Gimkit 的"团队模式 / 抢答 / 金币战"交互范式（借鉴其**节奏与反馈**，非照搬题目）。
- **竞赛赛制**：MATHCOUNTS 的 Team Round / Relay、AMC 8、Math Kangaroo 的团队化改造思路。

## 2. 设计原则与评估量规

一款"小组对抗计算游戏"要同时满足：**算得对、斗得起、讲得清、落得下**。

### 2.1 六条硬原则

1. **计算是内核，不是装饰**：每一回合的胜负都必须由"算对/算优"决定，而不是纯手速或运气。
2. **30 秒讲清规则**：主规则用一句话能说清（"凑 24""答对占格""先到 100"），深度靠变体叠加。
3. **对称公平 + 可翻盘**：双方起点相同；落后方有"追分机制"（如答错给对手加分、连胜加成、偷分），避免一边倒。
4. **技巧 > 运气，但留随机**：随机（洗牌/骰子/抽题）保证重玩性，但长期胜率应由计算与策略决定。
5. **双形态可落地**：每款都能"数字化（本站）"与"实体（纸牌/棋盘/黑板）"两开花，方便没有设备的课堂。
6. **差异化分层**：内置"基础档 / 进阶档 / 挑战档"，同一局不同小组可拿不同难度题（同分不同题）。

### 2.2 评估量规（给每款游戏打分，便于取舍）

| 维度 | 说明 | 权重 |
|---|---|---|
| 计算密度 | 单位时间有效运算次数 | 高 |
| 策略深度 | 是否存在非平凡决策 | 高 |
| 规则简洁 | 30 秒可讲清 | 中 |
| 公平性 | 是否可被运气/手速主导 | 中 |
| 可落地 | 数字/实体成本 | 中 |
| 扩展性 | 变体与年级跨度 | 中 |

## 3. 详细游戏方案

> **通用约定**：每款含「一句话 / 数学内核 / 人数道具 / 回合流程 / 计分胜负 / 三层难度 / 数字化要点 / 灵感来源」。计分默认"答对得分、答错失分或让对手得分"。

### 第一组 · 实时竞速（比谁算得又快又对）

#### R1 · 算 24 · 极速对决

- **一句话**：四张数字牌，用 `+ − × ÷` 和括号凑出 24，先做出者得分。
- **数学内核**：四则混合运算、运算优先级、括号、**逆向构造**（从目标 24 倒推）、中间结果可为分数。
- **人数 / 道具**：2–6 人/队；扑克牌（去 JQK 或按 11–13 计）或数字卡；数字形态用随机发牌。
- **回合流程**：
  1. 每轮翻出 4 张牌（1–13），全桌同时思考；
  2. 想出解法者按铃/拍桌，报出完整算式并由裁判验算；
  3. 正确则收走本轮牌得 1 分；错误则该轮判负（或让对手继续）。
- **计分 / 胜负**：先到 10 分，或限定轮数比总分；**多解加分**（同一组牌存在第 2 种解法时，能再说出一种 +1）。
- **三层难度**：
  - 入门：只用整数、允许有解且解多（如 3 4 6 8）；
  - 进阶：引入分数中间结果（如 3 3 8 8 → 8÷(3−8÷3)）；
  - 挑战：**Krypto 式**——5 张牌 + 一个目标数（不一定是 24），或限定"必须用括号改变优先级"。
- **数字化要点**：发牌器（`lib/engine/math.ts` 生成有解题组）、表达式解析校验（安全 eval → 自研 tokenizer）、倒计时与抢答键。
- **灵感来源**：24 Game；Krypto（5 牌 + 目标数）。

#### R2 · 算式接龙 · 团队接力

- **一句话**：上一题的答案，成为下一题的已知数，两队同时把"算式火车"越接越长。
- **数学内核**：口算流畅度、数字关系、验算、团队分工。
- **人数 / 道具**：每队 3–5 人排成一列；题库卡或屏幕。
- **回合流程**：
  1. 裁判给起点（如 `36`）与首个运算符；
  2. 队员 A 算出下一数 → 传给 B，B 接着算 → 依次到队尾；
  3. 3 分钟内比"接对的最长链"，或比"先跑完 10 环"。
- **计分 / 胜负**：每接对一环 +1，接错该环作废（可罚时 5 秒）；链最长或先跑完者胜。
- **三层难度**：
  - 入门：只加减、允许 10 以内；
  - 进阶：加减乘除混合、结果须落在指定区间（如 0–100）；
  - 挑战：**目标接龙**——每 3 环必须命中一个"目标数"，或限定"只准用 × ÷"。
- **数字化要点**：**分屏双赛道**（左右各一队输入区，同一题目流）；即时校验 + 错误高亮；音效节拍营造"接力感"。
- **灵感来源**：口算接龙；MATHCOUNTS Relay Round 的接力形式。

#### R3 · 数字拆弹 · 质因数限时

- **一句话**：屏幕上是一颗"炸弹"，倒计时内把它分解成质因数才能"剪线拆除"。
- **数学内核**：质数判定、分解质因数、整除性、最大公因数/最小公倍数。
- **人数 / 道具**：2 队对抗；数字形态（炸弹动画 + 质因数输入）或实体卡片。
- **回合流程**：
  1. 炸弹显示一个大数（如 360）与倒计时（如 30 秒）；
  2. 队伍轮流/分工输入质因数（2×2×2×3×3×5）；每填错一个因子亮一颗红灯；
  3. 全部正确即拆除，剩余时间折算分数。
- **计分 / 胜负**：拆除成功得基础分 + 剩余秒数；爆炸（超时/错满）则对手得分。
- **三层难度**：
  - 入门：两位/三位合数（如 84）；
  - 进阶：四位数 + 要求写成指数形式（2³×3²×5）；
  - 挑战：**公因数/公倍数炸弹**——给两个数求 GCD/LCM，或"求最小的 n，使 n! 中质因数 3 的个数达到 6"（答案 n=15）。
- **数字化要点**：因数输入即校验（不要求顺序）、指数自动合并、爆炸粒子动画；复用 `g5` 的 `factor-hunt` / `prime-dash` 判定逻辑。
- **灵感来源**：因数分解闯关；Prime Climb（质因数可视化）。
- **对齐**：`g5` 因数与倍数、`prime-dash`、`factor-hunt`。

#### R4 · 聪明格 / 数墙竞速

- **一句话**：在"算术数独（KenKen）"或"数字填字（Kakuro）"里，比谁先正确填满，且每一步都要用四则逆运算推理。
- **数学内核**：四则逆运算、约束满足、枚举与剪枝、逻辑推理。
- **人数 / 道具**：2 队同题竞速，或每人一版同难度；纸笔/屏幕。
- **回合流程**：
  1. 发放同难度题（如 5×5 KenKen）；
  2. 队伍协作填格：每行每列 1–n 不重复，且每个"笼"的运算达目标（如 `3× =12`、`2− =1`）；
  3. 先填完且全对者胜；错误格罚时。
- **计分 / 胜负**：竞速制（用时）+ 正确率；也可"限时解出题数"。
- **三层难度**：
  - 入门：4×4 KenKen，仅 `+ −`；
  - 进阶：5×5，四则混合笼；
  - 挑战：6×6 KenKen / 标准 Kakuro（行列和约束、禁止重复）。
- **数字化要点**：网格编辑器、笼运算校验、错误高亮、计时榜；题目用求解器生成 + 唯一解校验。
- **灵感来源**：KenKen（聪明格）、Kakuro（数墙/交叉和）。

> **本组小结**：竞速类最适合**开场热身与班级 PK**，节奏快、反馈强；R1/R4 上限很高，可作为"学优生挑战赛"项目。

### 第二组 · 同屏抢答对战（一屏、多队、抢答器定胜负）

#### B1 · 质数快抢 · 对抗版

- **一句话**：屏幕闪现数字，抢答"是不是质数 / 下一个质数是多少"；说合数必须附带一个因数。
- **数学内核**：质数判定、因数、整除性、2/3/5 的整除特征。
- **人数 / 道具**：2–4 队，每队一个抢答键（键盘 A/S/K/L 或实体抢答器）。
- **回合流程**：
  1. 屏幕显示一个数（如 91），倒计时 5 秒；
  2. 抢答队答"合数，因为 7×13"才得分；只喊"合数"不得分；
  3. 答错扣分并让出抢答权给对手。
- **计分 / 胜负**：答对 +2，理由完整 +1；答错 −1；先到 15 分。
- **三层难度**：
  - 入门：100 以内质合判定；
  - 进阶："下一个质数/上一个质数"、区间内质数个数；
  - 挑战：伪素数陷阱（如 91、133）、"两质数之和为奇数，则其中一个必为 2"、"两数之积为偶数，则其中至少一个是偶数"等推理题。
- **数字化要点**：复用 `prime-dash` 题库与判定；抢答器 + 锁定（先按者锁 2 秒）；抢答音效。
- **灵感来源**：质数快抢（现有）；Kahoot 抢答模式。

#### B2 · 估算擂台 · Fermi 最接近

- **一句话**：抛出一个"没法精确算、但能估"的现实问题，各队在限定时间给出数量级与理由，最接近者胜。
- **数学内核**：数量级、单位换算、比例推理、科学记数法、误差意识——**数学建模的入口**。
- **人数 / 道具**：2–6 队；题卡 + 小黑板/纸。
- **回合流程**：
  1. 出题（例："一间教室大约能装多少粒米？""全校一天大约用多少升水？"）；
  2. 各队 3 分钟讨论，写出"数值 + 一句推导"；
  3. 公布参考答案区间，按**数量级误差**判分。
- **计分 / 胜负**：与真值同数量级满分（如 3 分）；差 1 个数量级 1 分；理由清晰再加"过程分"。
- **三层难度**：
  - 入门：单位换算类（教室长宽高→体积）；
  - 进阶：人口/流量/密度类（需拆解因子相乘）；
  - 挑战：开放建模（"设计一次全校运动会的水与物资预算"），比方案合理性与量纲自洽。
- **数字化要点**：题库（问题 + 真值 + 区间）、队伍作答板、按对数误差自动算分；可做"揭晓动画"。
- **灵感来源**：Fermi problems（费米估算）；估算类竞赛题。
- **为什么"高大上"**：这是**真正的数学建模**，比单纯算数高一档，且答案不唯一、重推理。

#### B3 · 图表情报战

- **一句话**：给一张统计图/表，抢答"哪个月增长最快 / 某部分占比 / 预测下月"，把"读图"变成"抢情报"。
- **数学内核**：百分比、增长率、平均数、比例、读图与推断。
- **人数 / 道具**：2–4 队抢答；屏幕图表（折线/条形/扇形）。
- **回合流程**：
  1. 显示图表 + 一个问题（如"哪季度同比增幅最大？"）；
  2. 抢答并给出计算过程（如 (本−上)/上）；
  3. 答对得分，能指出"图表陷阱"（如纵轴不从 0 起）额外加分。
- **计分 / 胜负**：答对 +2；识破误导 +1；答错让权。
- **三层难度**：
  - 入门：直接读数、求总和；
  - 进阶：百分比、增长率、平均数比较；
  - 挑战：**图表误导识别**（截断纵轴、3D 错觉、比例失真）+ 据数据给决策建议。
- **数字化要点**：用 chart 组件（`g5` 已有 ChartLab 可复用）动态生成图表；问题模板化；抢答计时。
- **灵感来源**：统计图表读图训练；"数据素养"类课堂活动。
- **对齐**：`g5` 统计图、`g6` 百分数/扇形统计图。

#### B4 · 最强大脑 · 混合抢答

- **一句话**：综合题库（分数、小数、比例、几何、单位）阶梯式抢答，答错"偷分"给对手。
- **数学内核**：综合计算与概念辨析。
- **人数 / 道具**：2–4 队；题库按难度分绿/黄/红三档。
- **回合流程**：
  1. 每轮亮一题，难度越高分值越高；
  2. 抢答；答错则对手可选"接手作答"（偷分）；
  3. 阶梯推进（绿→黄→红），红题双倍分。
- **计分 / 胜负**：绿 1 / 黄 2 / 红 4 分；抢答错误 −1 并开放偷分；总分定胜负。
- **三层难度**：即绿/黄/红三档题库（可按年级切换）。
- **数字化要点**：搭建"对战题库"结构（复用各年级 `games/index.ts` 的题源）；抢答器 + 偷分状态机；排行榜。
- **灵感来源**：Kahoot / Blooket 团队模式；"最强大脑"式阶梯抢答。

> **本组小结**：抢答类最适合**全班投屏、分组举牌/抢答器**，一顿操作猛如虎，适合复习课与班会活动。B2 是"高大上"担当。

### 第三组 · 回合制策略对抗（算对→获得行动力→布局取胜）

#### S1 · 算术大富翁 · 领土战争

- **一句话**：答对计算题才能买地、升级、收租；租金和利息都按百分数现算。
- **数学内核**：百分数、利息、总价、四则混合、单位换算。
- **人数 / 道具**：2–4 队；棋盘（数字形态或实体打印）。
- **回合流程**：
  1. 掷骰前进，落地须答一道对应难度题；
  2. 答对可"买地/升级/收取路费"；答错则不能行动（或交罚金）；
  3. 收租 = 本金 × 利率 × 停留回合；到"银行"可存贷（复利规则）。
- **计分 / 胜负**：限定回合后净资产（现金 + 地产估值）最高者胜。
- **三层难度**：
  - 入门：整数总价、简单加减；
  - 进阶：小数金额、打折（八折/满减）；
  - 挑战：**复利与利率**——存 n 期本息、比较两种理财方案。
- **数字化要点**：棋盘状态机、资产账本、题目难度随地产等级提升；把百分数计算显式呈现（不做黑箱）。
- **灵感来源**：Monopoly（大富翁）；百分数/利率单元。
- **对齐**：`g6` 百分数、`g5` 小数。

#### S2 · 六边形战线（Hex）

- **一句话**：六边形棋盘，答对一题占一格，先用己方棋子把**对边连通**者胜——计算是"入场券"，连通是"战略"。
- **数学内核**：任意计算（可按单元配题：分数比较、小数运算、比大小）。
- **人数 / 道具**：2 队；七格/十一格六边形棋盘（屏幕或打印）。
- **回合流程**：
  1. 轮到你队 → 出一道题 → 答对可占任意一格，答错则对手占一格；
  2. 目标：用己色棋子在六边形上连成一条"左右（或上下）通路"；
  3. 同时要**堵**对手的通路。
- **计分 / 胜负**：先连通对边者胜；可三局两胜。
- **三层难度**：
  - 入门：7×7 小盘 + 简单口算；
  - 进阶：11×11 大盘 + 分数/小数计算；
  - 挑战：**限时抢格**（每题 10 秒）+ 双倍格（答难题才能占）。
- **数字化要点**：六边形网格坐标系统、连通性判定（并查集/DFS）、AI 或双人本地轮流。
- **灵感来源**：Hex（康威棋盘游戏）；"答题占地"机制。
- **为什么好**：规则极简，但**策略深度很高**（Hex 是无平局的博弈），计算只是门槛，思维是胜负手。

#### S3 · 坐标海战 · 函数战舰

- **一句话**：在坐标网格上布舰队、报坐标互轰；进阶要求"用直线关系描述位置"才能命中。
- **数学内核**：数对、方向、距离、比例、一次函数（y=kx+b 的粗略概念）。
- **人数 / 道具**：2 队；坐标网格（10×10）+ 舰队（可屏幕或纸面）。
- **回合流程**：
  1. 各自秘密布舰（占若干坐标）；
  2. 轮流报坐标"（3,5）"轰击；命中/未中反馈；
  3. **进阶规则**：报"这条直线上的舰"（给出经过两点的直线描述），或"与原点距离为 5 的点"。
- **计分 / 胜负**：先击沉对方全部舰船者胜；命中率计入复核。
- **三层难度**：
  - 入门：报坐标、认数对；
  - 进阶：计算两点距离、方向（东南/西北）；
  - 挑战：用**比例关系/直线方程**圈定范围，或用"镜像/旋转"描述位置。
- **数字化要点**：双网格、命中判定、坐标高亮；可加"距离提示"。
- **灵感来源**：Battleship（海战棋）；坐标与位置单元。
- **对齐**：`g6` 确定位置（数对/方向距离）、比例尺。

#### S4 · 二进制取子 · 尼姆博弈

- **一句话**：若干堆石子，轮流从**任意一堆**取走任意颗，取到最后一颗者（或最后一颗者输）；用**二进制异或**算必胜策略。
- **数学内核**：二进制、按位异或（nim-sum）、不变量、博弈论——**把"计算"升维成"证明最优"**。
- **人数 / 道具**：2 队；石子/筹码（数字形态可用堆动画）。
- **回合流程**：
  1. 摆 n 堆（如 3 堆：3、4、5 颗）；
  2. 双方轮流：选一堆，取走 ≥1 颗；
  3. 取走最后一颗者胜（正常版）；或取最后一颗者输（misère 版）。
- **计分 / 胜负**：每局胜者得分；可打系列赛。进阶要求"说出为什么这步必胜"。
- **三层难度**：
  - 入门：**抢 30**（每人报 1–3 个数，报到 30 者胜 → 模 4 策略）；
  - 进阶：两堆/三堆尼姆，靠试错找规律；
  - 挑战：**用二进制异或证明**——把所有堆数写成二进制，各列 1 的个数为偶数则"必败态"；并解释 misère 版差异。
- **数字化要点**：堆可视化、合法走法校验、可选"提示 nim-sum"；把二进制竖式并排显示，直观对照异或。
- **灵感来源**：Nim（尼姆游戏）；组合博弈论。
- **对齐**：`g6` 二进制的秘密（**天然契合**——把二进制从"转换"变成"用来赢"）。
- **为什么最"高大上"**：这是**用不变量获胜的严格策略**，已接近竞赛数学思维；但入门版（抢 30）小学生也能玩，分层极好。

> **本组小结**：策略类是"深度担当"。S2/S4 规则一句话、上限极高；S1 把百分数变成"经营游戏"；S3 把坐标变成"战争迷雾"。

### 第四组 · 卡牌 / 棋类化（把计算嵌进卡牌与棋盘）

#### C1 · 算式卡牌对决

- **一句话**：手牌是数字卡与运算符卡，每回合组合出"攻击力"（=算式结果）攻击对手，攻高者破防。
- **数学内核**：四则运算、优先级、**最优化**（用有限手牌打出最大/恰好值）、资源管理。
- **人数 / 道具**：2 队/2 人；数字卡 1–9、运算符卡（+ − × ÷、括号、"翻倍"）。
- **回合流程**：
  1. 每回合抽 2 张牌，用手牌组一个算式作为"攻击力"；
  2. 攻高者造成差值伤害；特殊卡可改优先级/翻倍；
  3. 对手 HP 归零者败。
- **计分 / 胜负**：剩余 HP 高者胜；或三局两胜。
- **三层难度**：
  - 入门：只有数字 + `+ −`；
  - 进阶：加 `× ÷` 与括号，考验优先级；
  - 挑战：**目标值爆发**——攻击力"恰好等于某目标"则触发暴击（鼓励精确计算而非一味求大）。
- **数字化要点**：卡牌 UI、算式构造器、实时算力显示、AI 出牌策略；把"为什么这样最大"做成复盘。
- **灵感来源**：TCG/卡牌对战；Math War；算式拼图（现有 `puzzle` 思路）。

#### C2 · 达芬奇密码 · 公牛与奶牛

- **一句话**：猜一个不重复的数字密码，每次反馈"几 A 几 B"（数字对且位置对 = A，数字对位置错 = B），最少次数破译。
- **数学内核**：排列组合、信息量、逻辑排除——**每猜一次要最大化"信息增益"**。
- **人数 / 道具**：2 队互为出题方/破译者，或人机；纸笔/屏幕。
- **回合流程**：
  1. 出题方设 4 位不重复数字（如 1–9 中选 4）；
  2. 破译方猜，得 "A/B" 反馈；
  3. 比谁用更少次数猜出（或同次数比用时）。
- **计分 / 胜负**：猜出所用次数越少分越高；出题方按"对手多花的次数"得分（双向博弈）。
- **三层难度**：
  - 入门：3 位、数字 1–6、允许提示"哪几位对了"；
  - 进阶：4 位不重复、标准 A/B；
  - 挑战：**允许重复**（10⁴ 空间）+ 讨论"最优首猜"（如 0123）与平均信息量。
- **数字化要点**：A/B 判定、历史记录、可开"候选集提示"（显示剩余可能数）；做组合数统计面板。
- **灵感来源**：Bulls and Cows（公牛与奶牛 / 猜数字）；Mastermind。
- **为什么好**：看似简单，实则是**组合计数 + 信息论**的活教材，越玩越懂"怎样问最值"。

#### C3 · 骰子博弈 · 期望值赌局

- **一句话**：轮流掷骰累加，可随时"收手落袋"或"再来一颗"；掷出 1（或重复）则本轮归零——先到 100 者胜。
- **数学内核**：概率、期望值、风险决策、模拟——**"继续还是收手"就是期望值问题**。
- **人数 / 道具**：2–4 队；骰子（数字/实体）。
- **回合流程**（以 Pig 为例）：
  1. 轮到你：反复掷骰，点数累加进"本回合池"；
  2. 掷出 1 → 本回合池清零，换人；掷出重复点数（变体）→ 同样爆掉；
  3. 随时可"收手"，把池内点数存入总分，然后换人。
- **计分 / 胜负**：先到 100 分者胜；可记录"收手决策"复盘期望值。
- **三层难度**：
  - 入门：单骰 Pig，凭直觉玩；
  - 进阶：**用期望值表**算"当前池值该不该收手"（如池分越高越该收）；
  - 挑战：双骰版 / "双倍区 + 保险"机制，计算不同策略的期望收益并比较。
- **数字化要点**：骰子动画、概率实时提示（可选关闭）、决策日志、期望值小工具；可回放"关键决策"。
- **灵感来源**：Pig（骰子游戏）；Shut the Box；期望值单元。
- **对齐**：`g5` 可能性/概率、`g6` 统计。

#### C4 · 汉诺塔 · 递推塔

- **一句话**：三根柱子移塔，大盘不能压小盘；比谁步数最少，或预测 n 层最少步数。
- **数学内核**：递推关系、指数增长、规律归纳——**从"玩"到"发现 2ⁿ−1"**。
- **人数 / 道具**：2 队；三柱 + n 个大小盘（屏幕或实体）。
- **回合流程**：
  1. 给定层数 n，两队比"最少步数完成"；
  2. 记录每层步数，找规律；
  3. 进阶：直接预测"10 层需要几步"（不许真搬）。
- **计分 / 胜负**：步数最少者胜；预测对规律额外加分。
- **三层难度**：
  - 入门：3–4 层实际操作；
  - 进阶：归纳 2ⁿ−1 并解释"先把上面 n−1 个搬走"；
  - 挑战：**"只能移到相邻柱"版**（三柱排成一线、每次只能移到相邻柱，最少步数变为 3ⁿ−1），或用**四柱汉诺塔**（Frame–Stewart，无简单通项，需讨论策略），比较"为什么柱数/限制一变，步数就暴涨"。
- **数字化要点**：拖拽移盘、合法校验、步数统计、步数曲线图（指数感）。
- **灵感来源**：Tower of Hanoi（汉诺塔）；递推与指数。
- **对齐**：`g6` 找规律/指数（延伸）。

> **本组小结**：卡牌棋类最"耐玩"，适合**社团/兴趣课/长线联赛**。C2/C3/C4 都自带"数学彩蛋"，玩完能顺势讲组合、期望、递推。

## 4. 赛制与赛事组织

一套好游戏，需要一个"能持续打"的赛制。四种常用模板：

| 赛制 | 适合 | 规则要点 | 时长 |
|---|---|---|---|
| **循环积分赛** | 班级常态 | 每两队都交一次手，胜 3/平 1/负 0，累计排名 | 2–4 周 |
| **瑞士轮** | 8 队以上 | 每轮同分/近分对局，5 轮后按积分+小分排名，公平且省时 | 半天 |
| **淘汰赛（含复活）** | 数学节 | 单败/双败淘汰，淘汰队进"复活挑战"再争名次 | 半天–1 天 |
| **主题闯关赛** | 单次活动 | 4–6 个"游戏站"轮转，每站限时积分，最后汇总 | 1–2 小时 |

**组织建议**：
- **时间盒**：单局 5–12 分钟，一节活动课跑 4–6 局；
- **难度分档发放**：同分组拿"基础题包"，学优组拿"挑战题包"，**同分不同题**保证公平又有区分度；
- **裁判即学优生**：让掌握快的学生当"验算裁判/出题人"，既减老师负担，又锻炼其表达；
- **积分可视化**：黑板/大屏"荣誉榜"实时更新，制造赛事氛围；
- **复盘 3 分钟**：每局后必问"哪一步最关键？还有别的算法吗？"——这是游戏"回到数学"的命门。

## 5. 与现有游戏站的集成（工程落地）

现有站点结构非常适合扩展：`g4`–`g6` 每个年级都有 `src/lib/games/`（题库 + registry）、`src/components/games/`（单游戏组件）、`src/components/ui/GameAnswerBar.vue`（答题条）、`src/lib/sound.ts` / `storage.ts`（音效/存档）。建议新增"对战专区"而**不改动**现有单人游戏：

1. **路由**：`src/pages/games/versus/index.vue`（对战大厅）+ `src/pages/games/versus/[slug].vue`（具体对战），与现有 `/games` 并列。
2. **对战引擎**（新增 `src/lib/versus/`）：
   - `turn.ts`：回合状态机（谁行动、计时、锁定抢答）；
   - `score.ts`：计分/偷分/连胜加成；
   - `board.ts`：棋盘类（Hex/海战/大富翁）通用网格与连通判定；
   - `rng.ts`：可复现随机（发牌/出题），便于回放与出题校验。
3. **同屏热座**：左右/上下分屏，两队各用一组按键（如 `A`/`L` 抢答，方向键/数字区作答），无需服务器即可本地双人。
4. **题目来源**：复用各年级 `games` 题库与 `lib/engine/math.ts` 生成器；对战题加"难度标签"（绿/黄/红）。
5. **反馈与氛围**：抢答锁音效、倒计时心跳、得分弹跳、胜负结算动画——借鉴 Kahoot/Blooket 的**节奏感**。
6. **可访问性与公平**：计时前给"读题条"（3-2-1），支持"无抢答器"模式（轮流制），照顾设备不足。

> 建议先做 **MVP：R1（24点）+ B1（质数快抢对抗）+ S2（Hex）**——覆盖"竞速/抢答/策略"三味，工程量小、演示效果最好，验证后再铺开 16 款。

## 7. 风险与注意事项

1. **别让"快"碾压"对"**：抢答类要给"读题条"，并设"答错让权"，避免手快乱按。
2. **防一边倒**：落后方"追分机制"（连胜加成、偷分、难题双倍）要让比赛可翻盘。
3. **防止"背答案"**：题库需**随机生成/洗牌**，同一局不重复；24 点等用生成器保证"必有解"。
4. **差异化不是放水**：同分不同题，让学困生在自己的难度里"够得着"，学优生"够得高"。
5. **时间失控**：每题强制倒计时；超时即判，避免拖堂。
6. **把"数学"留住**：每局结束 3 分钟复盘（"最优解是什么？为什么？"），否则容易退化成"比手速"。
7. **公平校验**：涉及随机（骰子/发牌）时用可复现随机种子，争议可回放。

## 9. 灵感来源（经典玩法，供自行检索核对）

> 以下为公开、成熟的游戏/平台名称，本方案仅借鉴其机制并做教学化改造；具体规则以官方说明为准。

**桌面 / 卡牌 / 博弈经典**
- 24 Game（24 点）· Krypto（5 牌 + 目标数）
- KenKen（聪明格 / 算术数独）· Kakuro（数墙 / 交叉和）
- Nim（尼姆游戏）与组合博弈论（二进制异或策略）
- Hex（康威六边形棋盘游戏）
- Battleship（海战棋）· Bulls and Cows（公牛与奶牛 / Mastermind）
- Pig（骰子游戏）· Shut the Box
- Tower of Hanoi（汉诺塔）
- Prime Climb（质因数桌面游戏）
- Monopoly（大富翁，百分数/经营改造）

**游戏化平台（借鉴节奏与团队模式）**
- Kahoot!（抢答 / 团队模式）
- Blooket（金币战 / 团队对抗）
- Gimkit（实时竞速 / 团队）

**竞赛赛制（借鉴团队化组织）**
- MATHCOUNTS（Team Round / Relay Round）
- AMC 8 · Math Kangaroo（袋鼠数学）· 华罗庚金杯 / 希望杯（题型与难度参考）

**教学法依据（通用共识，非具体引用）**
- 游戏化学习（game-based learning）与社会性学习对计算流畅度与动机的正向作用；
- "提取练习 + 即时反馈 + 间隔重复"提升运算自动化；
- 费米估算（Fermi problems）作为数学建模入门。

---

> **一句话总结**：把计算藏进"对抗"，让"算得对"变成"赢的关键"，再用策略/博弈/估算拉高上限——这正是"小组对抗 × 计算"小游戏既好玩又不简单的地方。
