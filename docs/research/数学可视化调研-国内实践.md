# 国内小学数学"例题可视化 / 动态演示"实践与教研调研

> 方法：联网检索 + 网页抓取；课标原文取自教育部官方 PDF 的 OCR 逐字摘录；教材内容取自工作区苏教版电子课本 PDF。推断处已标注。

## 摘要：五条可落地判断

1. **中国课堂认的可视化范式只有 7 个**：线段图、方格模型、数位表、剪拼转化、数轴、韦恩图、方向标。共同点是**"形"必须挂住一个"数"**——由课标对"几何直观"的定义直接决定。
2. 平台分两代：一代（洋葱学园、乐乐课堂）是动画微课，学生只能看；二代（希沃白板、人教智慧教学平台）是可拖拽课件，学生能动手。教研界更认二代。
3. 判据一句话：**这个动作学生能不能用学具亲手做？能做的，演示只做验证；不能做的（64 等分、滚圆一周、无限逼近），才是演示的主场。**
4. "花哨无效"的核心是同一件事：**动画把"过程"压缩成"结果"**。
5. 面积类骨架固定：**数方格→猜想→剪拼→找对应→推公式→回顾**；比与比例坚持**"先算比值再定义比例、先算比例尺再定义比例尺"**。
6. 结构校正：苏教版 2024 修订版中**比例尺在六上"六 放大与缩小"之内**；复式统计表、因数与倍数都在**五上**。

## 一、主流平台怎么讲例题

**洋葱学园**｜官网方法论自称"概念视觉化"："将抽象的数学概念转化为直观的动画演示……通过逻辑推演让思维一通百通"（[官网](https://yangcongxueyuan.com/)，已抓取）。做法（**据产品形态归纳**）：一节只切一个知识点，约 5–8 分钟（时长与"7000 多节动画课"来自渠道物料，[抖音](https://www.douyin.com/video/7413953071727840549)；官方称已破 1 万节，[网易转载](https://www.163.com/dy/article/K14IIFU1051480G7.html)）；分镜为"情境→图形推演算理→**同步打出算式**→例题→小结"。**"图形—算式"同步**最被模仿：几何变换时算式与数值逐行同帧写出，使"形的变化"与"数的变化"同帧发生，正对应课标"建立形与数的联系"。

**乐乐课堂**｜即"天天练"（[官网](https://www.leleketang.com/)）。一个知识点一个短视频、节奏极快、动画极简，"先给方法口诀，再套例题"。算理可视化弱于洋葱，题型覆盖强于洋葱。

**纳米盒**｜官网业务为"K9 数字课本服务平台""AI 图书融合出版"（[官网](https://www.namibox.com/)）。例题以**教材原页点读＋音频＋同步练习**为主，**不含几何动画推演**，不宜作动态演示参照。

**希沃白板／智慧课堂**｜自定位"为互动教学而生"（[希沃白板5](https://easinote.seewo.com/)、[希沃官网](https://www.seewo.com/)）。做"面积剪拼"的典型做法：预置平行四边形与**克隆的直角三角形**→学生上台**把三角形拖到另一侧**拼成长方形→**蒙层**遮结论，等学生说出对应关系再揭开→**课堂活动**（分类、连线、填空）即时检测。**价值不是自动演示，而是把动手权交回学生**。

**人教智慧教学平台**｜[zhpt.mypep.cn](https://zhpt.mypep.cn/)（人教数字出版，已验证；母站[人教社](https://www.pep.com.cn/)）。数字教材内嵌例题逐层展开、动画/音频、随堂练即时反馈。

**国家中小学智慧教育平台**｜教育部主导（[basic.smartedu.cn](https://basic.smartedu.cn/)）。"课程教学"按教材版本＋册次＋单元组织，每课配套**微课视频＋教学设计＋学习任务单＋课后练习**（覆盖 19 个版本 452 册教材）。**特征是"录像/微课＋可下载文档"，交互性弱**，宜作素材库。期刊以《中小学数字化教学》最对口（人教社主办，CN 10-1490/G4，[官网](https://zxxszhjx.pep.com.cn/)、[知网页](https://mall.cnki.net/magazine/magalist/ZSZJ.htm)）。

## 二、有效区与"伪直观"

**有效的 5 类**：① **等积变形/转化**（平行四边形、三角形、梯形、圆的面积，圆柱圆锥体积）；② **化曲为直/极限**（滚圆、绕线、圆面积 8→16→32→64 等分）；③ **图形的运动**（平移、旋转、轴对称、放大缩小）；④ **位置确定**（数对、方向＋距离，课标唯一点名）；⑤ **数与代数中的"形"**（线段图、面积模型、数轴）。①② 的理由共通：**静态图只有"剪之前""拼之后"两端，中间过程无法承载**。

**被批评为"花哨无效"**：① **只演结果不演过程**——直接"变"出拼好的长方形，学生未经历"为什么这样剪"，**把探究降级为观看**；② **用课件替代学生动手**——教研界主张"先操作、后演示"，试错才是几何直观的来源；③ **演示代替推理**——几何直观被窄化为"看图说话"，丢掉"由图形关系推出数量关系"；④ 无关音效转场、配色过杂、不可暂停回退；⑤ **极限过程一步到位**——由"圆"直接跳到"长方形"；⑥ **伪交互**——只有"点击继续"。

**学术侧**：知网摘要高度一致——几何直观"主要是指利用图形描述和分析问题……有助于探索解决问题的思路，预测结果"，并普遍引华罗庚"数缺形时少直观，形少数时难入微"（王金飞，《小学数学教育》2018 年 09 期，[CNKI 摘要](http://www.cnki.com.cn/Article/CJFDTOTAL-XUJY201809008.htm)，已抓取）。同类：[培养分析](http://www.cnki.com.cn/Article/CJFDTotal-XKCH201805442.htm)、[培养策略](http://www.cnki.com.cn/Article/CJFDTotal-SXYG201802058.htm)、[小学生几何直观能力的培养](http://www.cnki.com.cn/Article/CJFDTOTAL-JCJY201816022.htm)、[小学低年级](http://www.cnki.com.cn/Article/CJFDTotal-GSJY201820105.htm)；曹培英[同名解读](https://max.book118.com/html/2016/0501/41759290.shtm)被引最多；课件与操作的矛盾见《课件演示与学生动手操作的博弈》（题录）。

## 四、课标（2022 年版）原文及对课件的隐含要求

原文逐字摘自教育部官方 PDF（[课标 PDF](http://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf)、[教育部通知](http://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)）。

**"三会"**：会用数学的眼光观察现实世界，会用数学的思维思考现实世界，会用数学的语言表达现实世界。**小学阶段 11 个表现**：数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识、数据意识、模型意识、应用意识、创新意识（初中改称"观念/能力"）。

- **几何直观**："主要是指**运用图表描述和分析问题的意识与习惯**。能够感知各种几何图形及其组成元素，依据图形特征进行分类，根据语言描述画出相应的图形，分析图形的性质，**建立形与数的联系，构建数学问题的直观模型**；利用图表分析实际情境与数学问题，探索解决问题的思路。几何直观有助于把握问题的本质，明晰思维的路径。"
- **空间观念**："主要是指对空间物体或图形的形状、大小及位置关系的认识。能够根据物体特征抽象出几何图形，根据几何图形想象出所描述的实际物体，想象并表达物体的空间方位和相互之间的位置关系，**感知并描述图形的运动和变化规律**。"
- **数感**："主要是指**对于数与数量、数量关系及运算结果直观感悟**。能够在真实情境中理解数的意义……"
- **推理意识**："主要是指**对逻辑推理过程及其意义的初步感悟**。知道可以从一些事实和命题出发，依据规则推出其他命题或结论，能够通过简单的归纳或类比，**猜想或发现一些初步的结论**……"

**与可视化直接相关的原文**："引导学生**运用转化的思想**，推导平行四边形、三角形、梯形、圆等平面图形的面积公式"；"**借助动态演示或具体操作**，感悟两条直线平行与相交的差异"；"有条件的学校**可以借助信息技术，通过动态演示点的运动**帮助学生理解图形位置确定方式的合理性"；"让学生**借助操作探究**和掌握圆的周长和面积公式"；专节"**注重信息技术与数学教学融合**"提出"**利用数学专用软件等教学工具开展数学实验，将抽象的数学知识直观化**"。

**推出的 5 条硬要求**：① 图形变化时必须**同步出现算式/数值**；② 必须**可调参**（等分份数、底、高）；③ **不能取代动手操作**（课标原文是"动态演示**或**具体操作"）；④ 必须留出**"说理"环节**；⑤ **位置与方向类必须有交互式点的运动**。

## 五、中国课堂最认的 7 个可视化范式

**线段图**（行程、分数/百分数应用题、和差倍；把"量"变成"段"）｜**方格模型/面积模型**（面积公式、小数乘除法算理、乘法分配律；单位面积累加，长×宽与因数×因数同构）｜**数位表**（数的认识、进退位、小数与整数一致性；计数单位及其个数）｜**剪拼转化（割补/倍拼）**（面积公式推导；等积变形）｜**数轴**（数的顺序与大小、负数、近似数；位置即数值）｜**韦恩图/集合圈**（分类、公因数与公倍数、统计分类；包含与相交关系）｜**方向标**（确定位置；有序数对／极坐标雏形）。补充常用：点子图与百格图、表格、小棒与圆片、钉子板。

## 六、两类内容的标准演示步骤

### A. 面积剪拼：平行四边形／三角形／梯形／圆

**通用骨架**：情境 →（**数方格**）→ 猜想 → **剪拼** → 找对应 → 推公式 → 回顾。

**① 平行四边形**（五上三单元）→ **情境提问**：长方形公园 60×40 与平行四边形公园（底 60 m、邻边 50 m、高 40 m）哪个大 → **数方格**：每格 100 m²，每排 6 个、4 排共 2400 m² → **猜想**："任意一个平行四边形都能转化成长方形吗？"，小组剪拼 → **割补**：剪下直角三角形或直角梯形，**平移**后拼成长方形 → **找对应**：长＝底、宽＝高（**此时才定义**底与高：两条边之间的距离）→ **推公式** S＝ah → **回顾**转化思想。

**② 三角形**→ **衔接**："联系求平行四边形面积的过程，能通过转化解决吗？" → **尝试**：2 个完全一样的三角形可拼长方形，也可分剪拼长方形 → **一般化**："任意两个完全一样的三角形都能拼成平行四边形吗？" → **倍拼**成平行四边形 → **找对应**：底、高即三角形的底、高，**面积是它的一半** → **推公式** S＝ah÷2 → **文化拓展**：《九章算术》"半广以乘正从"、刘徽"**以盈补虚**"作为第二条割补路径。

**③ 梯形**→ **路径一（分割）**：分成两个三角形分别求面积再相加 → **路径二（倍拼）**：两个完全一样的梯形拼成平行四边形 → **一般化**验证 → **找对应**：平行四边形的底＝梯形**上底＋下底**、高＝梯形的高，面积是它的一半 → **推公式** S＝(a+b)h÷2 → **比较两条路径**。

**④ 圆**（六上五单元，极限思想，**动态演示唯一不可替代处**）→ **明确对象**："圆的面积指的是什么"，涂色表示 → **以 r² 为面积单位测量**：用边长等于半径的正方形去量，"小于 4 个面积单位""大于 2 个" → **给线索**：周长是直径的 π 倍，猜想面积是 r² 的 π 倍 → **联系旧知**："联系多边形面积公式的推导过程想一想"，小组把圆剪下来**先拼一拼、再比一比** → **等分递增**：8 份→近似平行四边形，16 份→更像，32 份→越来越像长方形，64 份→"**平均分的份数越多，拼成的图形越接近长方形**" → **找对应**：长方形面积＝圆面积，长相当于周长的一半 C/2＝πr、宽相当于半径 r → **推公式** S＝πr² → **应用**：喷水器、**圆环＝外圆面积−内圆面积**。
> 演示要点：**第 5 步是动态演示的主场，其余步骤尽量让学生自己动手。**

### B. 比与比例（六上四单元，延伸至六、七单元）

**主线**：比的意义 → 比与除法/分数的关系 → 比的基本性质 → 比例的意义 → 比例的基本性质 → 按比例分配 → 放大与缩小 → 比例尺 → 确定位置。

**① 比的意义**：情境"3 杯纯橙汁＋2 杯水" → **先用已有语言**说"纯橙汁的杯数是水的 3/2" → **再引出**"纯橙汁与水的杯数比是 3∶2" → 明确比号、前项、后项 → 用生活实例（男女性别比 105.07∶100、头长与身长比 1∶4）说明比是"两个数量之间的倍数关系"。**模型**：份数实物图。

**② 比与除法、分数的关系**：3∶2＝( )÷( )＝( )/( )，抽象到 a∶b＝a÷b＝a/b（b≠0）。**用三列并置表格**对照（此处不用韦恩图）。

**③ 比的基本性质**：**类比分数的基本性质**——前项和后项同时乘或除以相同的数（0 除外），比值不变。

**④ 比例的意义**：三张长方形名片（长宽比 3∶2、4∶3、6∶4）→ 各算比值 → 发现 3∶2 与 6∶4 比值相等 → "**表示两个比相等的式子叫作比例**" → 点明图①图③形状相同是因为比值相等。**模型**：长方形图示＋比值表格。

**⑤ 比例的基本性质**：由两个三角形写出 4 个比例 → 观察 → 发现"两个外项的积等于两个内项的积" → 字母化 a×d＝b×c → 分数形式交叉相乘推出 ad＝bc。**模型**：表格＋交叉相乘箭头图。

**⑥ 按比例分配**：36 公顷按 4∶5 种大豆玉米 → **先求总份数 4+5＝9** → 用**线段图/份数条**把总量分成 9 份 → 分别求。教材特意区分"**已知总量按比分配**"与"**已知一个部分量按比求另一个量**"（本单元易错点）。

**⑦ 放大与缩小**：**方格纸**上长方形每边放大到 2 倍 → 2∶1 放大、1∶2 缩小 → 明确"**大小变了，形状不变**" → 按 2∶1 放大直角梯形（每条边都放大到原来的 2 倍）。方格纸是**唯一能同时体现"边长按比变化"与"角度不变"的载体**。

**⑧ 比例尺**（在六单元内）：由草坪平面图（长 48 m 画成 4.8 cm）→ **先算** 4.8∶4800＝1∶1000 → **再定义**"图上距离∶实际距离＝比例尺" → 理解多重含义（图上 1 cm 表示实际 10 m；实际是图上的 1000 倍）→ 数值比例尺与**线段比例尺**互认 → 用比例式解"图上距离 5 cm，实际距离多少米"。**铁律：必须先"算"出来再"定义"。**

**⑨ 确定位置**（七单元，两层）：**第一层（行列→数对）**——座位图 → 规定列从左往右、行从前向后 → 用 (3, 4) 表示 → 在**方格图**上找点 → 用数对刻画平行四边形顶点，发现 AD∥BC 且相等；文化素材用围棋棋盘"星""天元"。**第二层（方向＋距离）**——浮雷情境 → **只报"东北方向"不够** → 引出"北偏东 30°" → **再问"还应该报告什么信息"** → 补上距离才能唯一确定；做法是从观测点**先画射线，再在射线上按比例尺量距离定点**。演示法要点：**先让学生体会"信息不足"，由认知冲突逼出规范表达。**
