## OCR 产物

`g4/ocr/upper/pages/` 每页三样（由 `ocr/src/ocr.swift` 生成，支持第 5 参数输出目录）：

| 产物 | 说明 |
| --- | --- |
| `pNNN.txt` | macOS Vision 文字识别（zh-Hans + en-US） |
| `pNNN.jpg` | 整页渲染图（图文对照） |
| `pNNN-N.jpg` | 自动裁出的插图区域 |

重跑命令（务必指定输出目录，避免覆盖一年级）：

```bash
swiftc -O ocr/src/ocr.swift -o ocr/src/ocr_bin
./ocr/src/ocr_bin "最新【苏教版】4年级数学课本•上册.pdf" 1 121 "g4/ocr/upper/pages"
```

## 注意事项

- 课本为新版（2026 年秋苏教版四年级上册），单元结构与此前旧版差异较大：
  旧版"升和毫升、两三位数除以两位数、观察物体、统计表"被重组为
  "两、三位数除以两位数、周长与面积、乘法数量关系、混合运算与数量关系（二）、
  多位数的认识、大数的运算"（周长与面积含面积单位与换算，多位数的认识含数字编码）。
- 综合实践单元（周长与面积的变化 / 制订旅游计划 / 度量衡的故事）无课本目录序号。
- 期末复习（书页 109–115）无 Lab。
