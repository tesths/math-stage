## OCR 产物

`g5/ocr/upper/pages/` 每页三样（由 `ocr/src/ocr.swift` 生成，支持第 5 参数输出目录）：

| 产物 | 说明 |
| --- | --- |
| `pNNN.txt` | macOS Vision 文字识别（zh-Hans + en-US） |
| `pNNN.jpg` | 整页渲染图（图文对照） |
| `pNNN-N.jpg` | 自动裁出的插图区域 |

重跑命令（务必指定输出目录，避免覆盖一年级）：

```bash
swiftc -O ocr/src/ocr.swift -o ocr/src/ocr_bin
./ocr/src/ocr_bin "最新【苏教版】5年级数学课本•上册.pdf" 1 131 "g5/ocr/upper/pages"
```

## 注意事项

- 课本为新版（2022 课标修订），单元结构与此前旧版差异较大（新增图形的运动/可能性/观察物体，小数乘除分两册）。
