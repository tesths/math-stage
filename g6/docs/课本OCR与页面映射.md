## OCR 产物

`g6/ocr/upper/pages/` 每页三样（由 `ocr/src/ocr.swift` 生成，支持第 5 参数输出目录）：

| 产物 | 说明 |
| --- | --- |
| `pNNN.txt` | macOS Vision 文字识别（zh-Hans + en-US） |
| `pNNN.jpg` | 整页渲染图（图文对照） |
| `pNNN-N.jpg` | 自动裁出的插图区域 |

重跑命令（务必指定输出目录，避免覆盖一年级/五年级）：

```bash
swiftc -O ocr/src/ocr.swift -o ocr/src/ocr_bin
./ocr/src/ocr_bin "最新【苏教版】6年级数学课本•上册.pdf" 1 120 "g6/ocr/upper/pages"
```

## 注意事项

- 课本为新版（2022 课标修订）。核心单元 7 个：小数乘除法（二）、混合运算与数量关系（三）、
  数与运算的再认识、比和比例、圆、放大与缩小、确定位置。
- 两个探索规律单元（二进制的秘密 p42-43、神奇的黄金比 p64-67）分别挂在 c3、c4 单元尾部；
  综合与实践（生活中的分段计费 p26-29、体育中的数学 p88-91）作为 Lab/游戏纳入对应单元。
- 比例尺（图上距离/实际距离换算）在"六 放大与缩小"单元（p98-102，书页 92-102）。
